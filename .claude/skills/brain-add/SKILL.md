# 자료를 세컨드 브레인에 저장

1. second-brain/ 의 허브 파일들을 보고 자료의 주제에 맞는 허브를 고른다. 애매하면 inbox/ 에 둔다.
2. 맨 위 속성에 출처, 날짜, 가져온 이유를 적는다.
3. 핵심 문장 3줄 요약을 만든다.
4. 노트 하나에 아이디어 하나만 담고, 관련 노트를 위키링크로 잇고 연결한 이유를 한 줄 쓴다.
5. second-brain/<허브>/ 에 저장하고 허브 파일의 "세부 지식"에 위키링크를 추가한다.
