# AI 대화 지식·스킬 세컨드브레인 업로드

사용자가 AI와 대화하면서 얻은 모든 지식, 트러블슈팅, 프롬프트, 반복 업무 절차를 놓치지 않고 세컨드브레인에 체계적으로 축적한다.

## 1. 입력 받기
사용자에게 아래 중 하나로 대화 자료를 받는다.
- 현재 대화 세션 전체 ("방금 대화한 내용 전부 세컨드브레인에 올려줘")
- 다른 AI(ChatGPT, Gemini, Claude 웹 등)에서 복사해 붙여 넣은 대화 텍스트
- 내보내기(Export)한 마크다운/텍스트/JSON 파일 경로

## 2. 개인정보 및 기밀 자동 필터링 (필수)
파일을 저장하기 전에 반드시 아래 민감 정보를 스캔해 제거하거나 `<비공개>`, `<회사명>` 등으로 비식별화한다.
- 실명, 전화번호, 이메일 주소, 주민등록번호, 집 주소
- 계좌번호, 카드번호, 비밀번호, API 키, 토큰, 사내 내부 IP/계정
- 외부 유출이 금지된 사내 기밀 수치 및 원본 파일 내용 (필요 시 `.gitignore`로 차단된 `company-local/`에만 로컬 저장)

## 3. 지식 · 기억 · 스킬 3종 자동 분류
대화에서 추출한 내용을 아래 3가지로 나누어 사용자에게 저장 목록을 먼저 표로 보여 주고 승인을 받는다.
1. **영구 지식 (`second-brain/<허브>/<주제>.md`)**: 두고두고 꺼내 쓸 노하우, 개념, 오류 해결법, 가이드. 노트 1개 = 아이디어 1개 원칙. 끝에 상위 허브 위키링크 기재.
2. **날짜별 기억 (`MEMORY/YYYY-MM-DD-<주제>.md`)**: 이번 대화에서 확정된 결정, 일정, 선호 사항. `MEMORY/_index.md`에도 한 줄 추가.
3. **실행형 스킬 (`.claude/skills/<스킬명>/SKILL.md`)**: 대화 중 효과적이었던 프롬프트나 2번 이상 반복할 작업 절차는 50줄 이내 경량 스킬로 압축 생성.

## 4. 반영 및 대시보드 동기화 (승인 후)
1. 승인된 노트·기억·스킬 파일을 생성하거나 기존 노트에 병합한다.
2. `node dashboard/build.mjs`를 실행해 끊어진 위키링크가 0개인지 확인한다.
3. 사용자가 원하면 변경된 파일만 골라 `git add` → `git commit` → `git push`로 GitHub 및 웹 대시보드에 즉시 반영한다.
