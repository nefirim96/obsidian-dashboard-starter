# 내 업무 노트 처음 설정

이 볼트는 빈 틀이다. 사용자에게 맞게 채운다. **파일을 고치기 전에 계획을 보여 주고 승인을 받는다.**

## 1. 인터뷰 (한 번에 하나씩, 짧게)
아래를 차례로 묻는다. 사용자가 "알아서"라고 하면 합리적인 기본값을 제안한다.
1. 이름(또는 별명)과 하는 일 — 직무, 업종, 회사/학생/프리랜서 등
2. 지식을 모을 분야 3~8개 — 예: 자금업무, 회계, 영업, 게임개발, 유튜브, 공부. 각 분야가 "업무"인지 "창작"인지도 묻는다.
3. 자주 반복하는 일 2~5개 — 스킬로 만들 후보 (예: 주간 보고서 초안, 회의록 정리, 릴스 대본)
4. 정해진 시간에 하는 일 — 루틴 후보 (예: 매일 아침 일정 확인, 매주 금요일 정리)
5. 집 PC와 회사 PC를 따로 쓰는지, 각각 주로 보는 분야
6. 쓰는 도구 — 메일·캘린더·노션 등 (연결은 나중에 해도 된다고 알린다)
7. 답변 말투 선호

## 2. 계획 보여 주기
인터뷰 결과로 만들 것을 표로 보여 주고 승인을 받는다: 허브 목록(영문 폴더 이름·한글 표시 이름·업무/창작), 스킬, 루틴, 프로필.

## 3. 만들기 (승인 후)
- **허브**: `second-brain/<영문-이름>.md` 와 같은 이름의 폴더. 허브 frontmatter:
  ```
  ---
  title: 한글 표시 이름
  type: hub
  area: work 또는 create
  color: '#7ea6c8'   # 허브끼리 겹치지 않게 차분한 색
  ---
  ```
  본문에 한 줄 설명과 `## 세부 지식` 목록, 끝에 `상위: [[AGENTS]]`.
  각 허브에 시작 노트 1~2개를 만든다 (사용자가 말한 내용으로. 지어내지 않는다).
- 쓰지 않는 기본 허브(work·study·ideas)는 사용자에게 물어 지우거나 이름을 바꾼다.
- **AGENTS.md**: 이름/역할, 말투, 길잡이의 허브 링크 목록을 새 허브로 고친다.
- **프로필**: `profiles/home.md`, `profiles/work.md` 의 `focus:` 에 각 PC에서 보는 허브 폴더 이름을 쉼표로 적는다. PC를 하나만 쓰면 home 만 채운다.
- **스킬**: `.claude/skills/<영문-이름>/SKILL.md`. frontmatter 에 name, description(언제 쓰는지 한 문장), scope(common·home·work), title(한글). 본문은 3~6단계 절차.
- **루틴**: `routines/<영문-이름>.md`. frontmatter 에 name, title, scope, schedule(예: 매일 08:30).
- **MEMORY/내-선호.md** 에 말투·선호를 적는다.

## 4. 확인
1. `node dashboard/build.mjs` 를 실행해 "끊어진 링크"가 0개인지 본다. 있으면 고친다.
2. 기록 훅 설치를 권한다: `node dashboard/setup.mjs` — 이 명령은 `~/.claude/settings.json` 을 고치므로 (백업은 자동) **실행 전에 사용자에게 확인을 받는다.**
3. `node dashboard/serve.mjs` 로 서버를 켜고 http://localhost:8765 를 열어 보라고 안내한다.

## 5. 마무리 안내
- 다른 PC와 같이 쓰려면 이 폴더를 **비공개** 깃허브 저장소로 올리라고 안내한다 (개인 기록이므로 공개 금지). 사용자가 원할 때만 대신 만들어 준다.
- 비밀번호, 계좌번호, API 키는 노트에 적지 않는다고 알린다.
